# Example

🇫🇷 [Français](README.fr.md) · 🇪🇸 [Español](README.es.md)

A starting point for a new plugin: a mod with one slash command, `/example`, that says hello.

## Install

In Claude Code, add the tinwright marketplace once, then install the plugin:

```text
/plugin marketplace add tinwright/ai-apprentice
/plugin install example@tinwright
```

## How to use it

Type `/example Ada` in Claude Code. It answers "Hello, Ada!", which shows the plugin is installed and
its hooks run. To make your own plugin from the same shape, run `npm run create` in this repository.
