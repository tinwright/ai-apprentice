# Example

🇬🇧 [English](README.md) · 🇪🇸 [Español](README.es.md)

Un point de départ pour un nouveau plugin : un mod avec une seule commande, `/example`, qui dit bonjour.

## Installation

Dans Claude Code, ajoutez une fois la place de marché tinwright, puis installez le plugin :

```text
/plugin marketplace add tinwright/ai-apprentice
/plugin install example@tinwright
```

## Comment l'utiliser

Tapez `/example Ada` dans Claude Code. Il répond « Hello, Ada! », ce qui montre que le plugin est
installé et que ses hooks s'exécutent. Pour créer votre propre plugin sur le même modèle, lancez
`npm run create` dans ce dépôt.
