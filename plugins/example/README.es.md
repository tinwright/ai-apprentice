# Example

🇬🇧 [English](README.md) · 🇫🇷 [Français](README.fr.md)

Un punto de partida para un plugin nuevo: un mod con un solo comando, `/example`, que saluda.

## Instalación

En Claude Code, añade una vez el marketplace de tinwright y después instala el plugin:

```text
/plugin marketplace add tinwright/ai-apprentice
/plugin install example@tinwright
```

## Cómo usarlo

Escribe `/example Ada` en Claude Code. Responde «Hello, Ada!», lo que demuestra que el plugin está
instalado y sus hooks se ejecutan. Para crear tu propio plugin con la misma forma, ejecuta
`npm run create` en este repositorio.
